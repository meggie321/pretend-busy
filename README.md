# 假装很忙（Pretend To Be Busy）

2D 办公室摸鱼反应小游戏 —— 老板随时从左右两扇门出现，你要在他走到身后之前把屏幕从「摸鱼」切到「工作」，顺手把泡面和手机收好。

- **平台**：PC 网页版（单文件，离线可运行，无任何外部依赖 / CDN / 美术素材）
- **运行**：直接双击 `index.html`，或用浏览器打开；推荐 Chrome / Edge，窗口比例 16:9
- **分辨率**：逻辑分辨率 1280×720，自动等比缩放适配窗口，支持鼠标、键盘与触屏点击

## 一、怎么玩

| 操作 | 键位 / 方式 | 说明 |
| --- | --- | --- |
| 切换屏幕 | `空格` / `Tab` / 点击底部大按钮 | 摸鱼内容 ⇄ 工作内容 |
| 藏泡面 | `1` / 点击按钮 | 老板检查时桌面有泡面要扣分 |
| 收手机 | `2` / 点击按钮 | 同上；两样都摆着扣 16 分 |
| 接电话 | `P` / 点击按钮 | 电话响 4 秒内接起 +5 分，超时 −12 分 |
| 重启电脑 | `R` / 点击按钮 | 停电黑屏后必须重启，黑屏期间无法切换屏幕 |
| 打招呼 | `H` / 点击按钮 | 同事路过时挥手 +4 分 |
| 暂停 / 静音 | `Esc` / `M` | 暂停界面可继续、重开、回菜单 |

**判定规则**：老板走到身后会停留 1~2 秒检查屏幕（随时间变长）。停留期间只要屏幕是「摸鱼内容」就被抓（有 0.35 秒反应宽限）；是「工作内容」则伪装成功得分并累积连击。停电黑屏时老板看不出问题，不抓人但也不给分。

**得分**：成功伪装 `+10`（连击每级 +3，封顶 +22）；被抓 `−15` 且连击清零；桌面没收好的泡面 / 手机各 `−8`；没接电话 `−12`；接电话 `+5`；打招呼 `+4`。

**胜负**：

- 胜利：坚持到下班时间（实习生 3 分钟 / 社畜 5 分钟）**且**摸鱼积分达到指标（150 / 300 / 600 分）
- 失败：被抓 3 次，或摸鱼积分归零
- 评级：被开除 → 摸鱼小白（<200）→ 普通社畜（200+）→ 摸鱼高手（450+）→ 摸鱼大师（800+）

**成就**（本地存档 `localStorage`）：成功下班、从未被抓、摸鱼大师、影帝（一局内 3 次桌面干干净净）、连击王（5 连击）、被开除。
出场地板会记录最高积分、累计经验与等级。

## 三、内置自测（开发/回归用）

浏览器打开 `index.html?selftest=1`，页面左上角会输出 34 项断言结果（PASS/FAIL），并把结果写进 `document.title`（`SELFTEST PASS` / `SELFTEST FAIL n`），方便无头浏览器抓取：

```
PASS | 老板速度随时间递增  [92 -> 202]
PASS | 工作屏幕通过检查并加分  [points 70 -> 80, success 1]
PASS | 摸鱼屏幕被老板抓到  [catches=1]
PASS | 完美玩家能坚持到下班  [outcome=survived t=300]
PASS | 完全不伪装的玩家被开除  [outcome=fired, catches=2, points=0]
...
--- SELFTEST PASS ---
```

覆盖：难度递增单调性、切换/停电锁定、伪装成功与被抓判定、隐藏动作扣分、电话与停电事件、老板突然回头、评级边界、以及两局 5 分钟全程模拟（完美玩家应存活且达标、完全不操作的玩家应被开除）、大时间步长下的健壮性。
自测会临时跑完整局，结束后自动还原你的存档。

命令行跑一次（Windows，Edge 无头模式）：

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --disable-gpu `
  --virtual-time-budget=20000 --dump-dom "file:///C:/路径/index.html?selftest=1" | Select-String "SELFTEST"
```

调试用查询参数：`?auto=1` 直接开局、`?boss=1` 摆出"老板正在检查"的画面、`?freeze=1` 冻结逻辑只渲染（方便截图）、`?diff=easy|normal|hard` 指定难度。

## 五、已知取舍

1. **难度解锁**：困难模式默认可选，没有做"必须升级才解锁"的门槛，避免劝退。
2. **进程解锁**：只做了经验/等级展示，未做新内容解锁（文档中标为可选项）。
3. **多人 / 手机版 / 自定义内容 / 剧情模式**：未实现（文档中标为可扩展方向）。
4. 音效首次播放需要一次用户交互（浏览器自动播放策略），点击开始或按空格后即正常。
